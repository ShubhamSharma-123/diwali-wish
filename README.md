# Shubh Deepawali — From Shubham

Premium, responsive React + Tailwind CSS Diwali celebration website.

## Start

```bash
npm install
npm run dev
```

Open the local URL displayed by Vite.

## Production build

```bash
npm run build
```

Deploy the `dist` folder to Vercel or Netlify.

## Features

- Elegant royal burgundy and gold visual identity
- CSS-illustrated animated diyas and floating sparks
- Interactive fireworks celebration
- Four original wishes with selection
- Personalized greeting card with recipient name
- Native share / WhatsApp fallback and copy-to-clipboard
- Shareable `?to=Name` URL personalization
- Responsive layout and reduced-motion support
